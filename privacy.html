Privacy policy

Last updated 26 November 2026

The short version: BooBoard works offline and sends nothing anywhere. It has no internet permission, so it cannot send what you type or say to us or to anyone else. We have no servers that collect your data, and no account to sign in to.

The BooBoard app

BooBoard is an Android keyboard. Its release builds do not ask Android for internet or network access, and the build fails if that permission ever appears. You can check this in the app's permissions on your phone or in the source code.

  • What you type stays on your phone. Predictions, autocorrect, swipe typing and translation all run on the phone.
  • What BooBoard learns (new words, phrases and clipboard history) is stored on your phone, encrypted with a key held in Android Keystore. It is never synced or backed up to any cloud. You can see how much is stored, and delete it, in BooBoard's Privacy screen.
  • Incognito: nothing is learned in password fields, in browser incognito tabs, or in apps you choose.
  • Voice typing (English) runs on your phone. Audio stays in memory while you dictate and is never saved or sent.
  • Backups are encrypted files that you create and keep. BooBoard never uploads them.
  • Permissions: BooBoard asks only for the microphone (for voice typing, and only if you turn it on) and vibration (for key taps).
  • No analytics, no ads, no crash reporting and no tracking of any kind.

Optional packs

Voice, translation and some dictionaries come as optional packs. BooBoard never downloads them itself: when you choose Download, your web browser fetches the file from GitHub, and you then import it into BooBoard. That download is between your browser and GitHub, under GitHub's privacy statement. Packs contain data only, never code, and BooBoard checks their signature before installing them.

This website

booboard.com has no cookies, no analytics, no trackers and no forms, and it loads nothing from any other site: its fonts, images and scripts are all served from booboard.com. The site is hosted on GitHub Pages. Like most web hosts, GitHub keeps standard server logs, which can include your IP address, for security and to run the service; see GitHub's privacy statement. We don't receive or look at those logs.

Downloading BooBoard from the releases page also goes through GitHub.

Children

BooBoard collects no personal information from anyone, including children.

Changes

If this policy changes, the new version will be posted on this page with a new date. Because BooBoard has no internet access, a change to this policy can never make the app start sending data; that would need a new app version that asks for internet access, which Android would show you.

Contact

Questions about privacy: open an issue on GitHub.
